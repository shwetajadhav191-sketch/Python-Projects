# ✂️ Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game built with Python. Play against the computer for **5 rounds** and see who gets the highest score.

## 🎮 Features

- User vs Computer gameplay
- Random computer choices
- Score tracking
- 5-round match
- Beginner-friendly Python project

## 🛠️ Technologies Used

- Python
- random module

## ▶️ How to Run

1. Clone this repository or download the project.
2. Open a terminal in the project folder.
3. Run:

```bash
python rock_paper_scissors.py
```

## 📖 How to Play

Enter your choice:

```
1 - Rock
2 - Paper
3 - Scissors
```

The computer will randomly choose its move.

After each round, the current scores are displayed.

## 📸 Example

```
Enter your choice (1-3):

1. Rock
2. Paper
3. Scissors

You: Rock
Computer: Scissors

YOU WIN!

You: 1
Computer: 0
```
