# 👻 The Haunted Mansion

A text-based adventure game built with Python where the player explores a haunted mansion, makes choices, encounters ghosts, and searches for hidden treasure.

## 🎮 Features

- Interactive story
- Multiple choices
- Different game paths
- Random battle outcomes
- Treasure hunt adventure
- Beginner-friendly project

## 🛠️ Technologies Used

- Python
- random module

## ▶️ How to Run

1. Clone this repository or download the project.
2. Open a terminal in the project folder.
3. Run:

```bash
python terminal_game.py
```

## 📖 Gameplay

- Enter the haunted mansion.
- Choose different paths.
- Meet mysterious ghosts.
- Find the magic key.
- Battle the giant ghost.
- Unlock the treasure chest and win!

Every decision changes your adventure.

## 📸 Example

```
Welcome to The Haunted Mansion!

Do you want to enter?

1. Enter the mansion
2. Run away
```
